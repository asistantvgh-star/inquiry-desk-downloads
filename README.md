# Inquiry Desk — Windows Download

Inquiry Desk is an offline-first desktop application for managing inquiry records on an individual Windows computer.

## Current release

**Version:** 3.9.0  
**Platform:** Windows  
**Installer:** `Inquiry Desk-Setup-3.9.0.exe`

The installer has been built and smoke-tested. The application has also been manually tested for its core inquiry workflow, response templates, backup/restore, and CSV export.

> The installer file still needs to be attached to this repository's GitHub Release before a public download link is available. Check the **Releases** section for the installer.

## Installation

1. Download `Inquiry Desk-Setup-3.9.0.exe` from the latest release.
2. Run the installer on Windows.
3. Launch **Inquiry Desk** from the Start menu.

Local use does not require an account, activation key, subscription, or internet connection. Each computer stores its own local data. Shared workspace is optional and requires separate server setup.

## Included and known limitations

- Create, edit, search, filter, and manage inquiry records.
- Dashboard and response templates.
- Local backup and restore.
- CSV export.
- Offline-first local operation.

**Not yet implemented:** automation/email integration and complete in-app team administration. Do not rely on these features being available.

This is an independent replacement application. Exact visual or functional parity with any other product has not been established.

## Data and backups

Records are stored locally on the computer. Use the app's backup feature regularly, and keep backup files in a safe location.
